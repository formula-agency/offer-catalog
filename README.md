# Каталог офферов

Откройте `index.html` в браузере. Каталог работает локально и не требует установки программ или подключения к интернету.

В каталог попадают только изображения из папок с названием `Обработанные`. Тип оффера, район и ЖК берутся из структуры папок, комнатность — из названия файла.

## Как добавить новые офферы

1. Положите готовое изображение в подходящую папку `Офферы Новостройки… / Тип / Район / ЖК / Обработанные` в одном из трёх наборов офферов.
2. Запустите `Обновить каталог.cmd`.
3. Обновите страницу в браузере.

Скрипт `generate-offers-data.ps1` заново формирует `offers-data.js`, поэтому вручную редактировать файл данных не нужно.

## Метка «Не актуально»

На каждой карточке и в окне просмотра есть кнопка `Не актуально`. Помеченный оффер сразу скрывается из общего каталога и переносится в отдельный раздел, где его можно вернуть в актуальные.

Метки сохраняются в браузере менеджера и не сбрасываются после запуска `Обновить каталог.cmd`. Если оффер удалён из папки `Обработанные`, его устаревшая метка автоматически очищается. Между разными браузерами и устройствами метки не синхронизируются.
