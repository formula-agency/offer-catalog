# Каталог офферов

Откройте `index.html` в браузере. Каталог работает локально и не требует установки программ или подключения к интернету.

В каталог попадают только изображения из папок с названием `Обработанные`. Тип оффера, район и ЖК берутся из структуры папок, комнатность — из названия файла.

## Как добавить новые офферы

1. Положите готовое изображение в подходящую папку `Офферы Новостройки / Тип / Район / ЖК / Обработанные`.
2. Запустите `Обновить каталог.cmd`.
3. Обновите страницу в браузере.

Скрипт `generate-offers-data.ps1` заново формирует `offers-data.js`, поэтому вручную редактировать файл данных не нужно.
